TIDAK CETAK ZONAMAIN

Baris ZonaMain yang ORDER ID-nya tidak ditemukan pada PARTNER ID XPAY/LEONPAY.

TIDAK CETAK P2M

Baris XPAY/LEONPAY yang PARTNER ID-nya tidak ditemukan pada ORDER ID ZonaMain.

USERID SELISIH

Total Coin Admin per userid dikurangi total JUMLAH ZonaMain per userid. Order ID ZonaMain penyebab selisih ikut ditampilkan. Untuk nominal kembar, pencocokan menggunakan waktu transaksi terdekat.

TIDAK LEWAT KOIN IDN

Pasangan USERID + NOMINAL dari ZonaMain yang tidak ditemukan sebagai pasangan TO + COIN di Coin Admin.
Logika yang digunakan:
1. TIDAK CETAK ZONAMAIN = ORDER ID ZonaMain tidak ada di PARTNER ID XPAY.
2. TIDAK CETAK P2M = PARTNER ID XPAY tidak ada di ORDER ID ZonaMain.
3. USERID SELISIH = total Coin Admin per userid − total ZonaMain per userid, beserta Order ID ZonaMain yang belum memiliki pasangan transaksi Coin Admin. Untuk nominal yang sama berulang, transaksi dicocokkan berdasarkan waktu terdekat.
4. TIDAK LEWAT KOIN IDN = kombinasi userid + nominal ZonaMain tidak ada di kombinasi userid + nominal Coin Admin.
